# প্রশ্নভান্ডার – MCQ Practice & Mock Test (GitHub Pages)

একবার GitHub-এ আপলোড করলে `index.html` / `assets/` আর ছুঁতে হবে না। নতুন প্রশ্ন যোগ করতে শুধু `data/` ফোল্ডারের একটা ফাইল খুলে পেস্ট করুন।

## ফাইল কাঠামো
```
index.html            ← ডিজাইন (আর বদলাবেন না)
assets/style.css, app.js
data/index.js         ← ২২টি কালেকশন + সাবসেকশনের টাইটেল (একবার সাজানো আছে)
data/shakil-sir.js    ← শাকিল স্যারের সব প্রশ্ন
data/bcs.js           ← বিসিএসের সব প্রশ্ন
data/friends.js       ← বন্ধুদের প্রশ্ন
... (প্রতি কালেকশনের জন্য একটা ফাইল)
```

## নতুন পরীক্ষা যোগ করা (সবচেয়ে সহজ)
1. যে কালেকশনে দেবেন তার ফাইল খুলুন (যেমন `data/friends.js`)।
2. সাবসেকশনের `[ ]` এর ভেতরে এটা বসান, মাঝে প্রশ্নগুলো সাধারণ লেখার মতো পেস্ট করুন:

```js
{ id: "exam-2", title: "মডেল টেস্ট ০২", negative: 0.5, duration: 30, text: `
১. প্রশ্ন এখানে?
ক) অপশন ১
খ) অপশন ২
গ) অপশন ৩
ঘ) অপশন ৪
উত্তর: গ
ব্যাখ্যা: (ঐচ্ছিক)

২. পরের প্রশ্ন…
` },
```
3. GitHub-এ ফাইলটা আবার আপলোড (Commit) করুন। শেষ।

নিয়ম:
- `id` প্রতি সাবসেকশনে আলাদা। একবার দিলে বদলাবেন না (স্কোর ও ভুলের খাতা এই id ধরে চলে)।
- `duration` মিনিটে (`0` = টাইমার নেই), `negative` = ভুলে কাটা নম্বর।
- অপশনে `ক) খ) গ) ঘ)` বা `a) b) c) d)` দুটোই চলে। উত্তর: `উত্তর: গ` / `Ans: c` / `সঠিক: খ`।
- ভুল ফরম্যাট থাকলে হোম পেজে হলুদ "⚠️ সমস্যা পাওয়া গেছে" বক্স দেখাবে, কোন সেটের কোন প্রশ্ন বলে দেবে।

পুরনো ফরম্যাটও চলে: `questions: [ { q: "…", options: {a:"…",b:"…",c:"…",d:"…"}, ans: "c" } ]`

## ✨ নতুন টাইটেল + সাবটাইটেল + টেস্ট (পুরনো কোনো ফাইল না ছুঁয়ে)
1. `TEMPLATE-new-test.js` কপি করে নাম বদলান (যেমন `ncert-physics-1.js`) এবং `data/` ফোল্ডারে আপলোড করুন।
2. ফাইলের ভেতরে `collection` (টাইটেল), `sub` (সাবটাইটেল) আর টেস্ট বদলে নিন। শেষ।
3. একই টাইটেলের আরেকটা টেস্ট চাইলে আরেকটা নতুন ফাইল, একই `collection.id` ও `sub.id` দিয়ে। আগের টাইটেলে নিজে থেকে জোড়া লাগবে।

- কালেকশন/সাবসেকশন আগে থেকে থাকলে শুধু `id` দিলেই চলে (`collection: "ncert"`, `sub: "physics"`)।
- `data/` এর সব `.js` ফাইল GitHub API দিয়ে নিজে খুঁজে লোড হয় (`index.js` ছাড়া)। আপলোডের ১–২ মিনিট পর দেখা যাবে।
- কাস্টম ডোমেইনে বা API সীমা পেরোলে `data/index.js` এ `PB.repo = "ইউজার/রিপো"` অথবা `PB.files = ["ফাইলের-নাম.js"]` দিন।
- কোনো ফাইলে কোড ভুল থাকলে হোম পেজের হলুদ ⚠️ বক্সে ফাইলের নাম ও লাইন দেখাবে।
- পুরনো `PB.sets(...)` ফরম্যাটও চলে, এখন একই সাবসেকশনে একাধিক ফাইল জোড়া লাগে (আগে শেষেরটা বাকিগুলো মুছে দিত)।

## GitHub Pages চালু করা
Repo → Settings → Pages → Deploy from a branch → `main` / (root) → Save। কিছুক্ষণ পর `https://<username>.github.io/<repo>/`।
(`index.html` সরাসরি ডাবল-ক্লিক করেও কম্পিউটারে চলে।)

## ফিচার
- 🪗 অ্যাকর্ডিয়ন হোম: কালেকশন → সাবসেকশন → এক্সাম কার্ড
- 🧪 পরীক্ষা মোড (টাইমার, নেগেটিভ মার্কিং, স্কোর, রিভিউ) / 📖 প্র্যাকটিস মোড (সাথে সাথে সবুজ/লাল)
- ❌ ভুলের খাতা: ভুল প্রশ্ন নিজে জমা হয়; "ভুলগুলো আবার দিন"; ঠিক করলে বাদ যায়
- 🎲 র‍্যান্ডম মিক্স (কালেকশন বা সাবসেকশন থেকে ১০/২০/৫০ প্রশ্ন)
- 🔀 প্রশ্ন ও অপশন শাফল (সঠিক উত্তর ঠিক থাকে; "উপরের সবগুলো" ধরনের অপশন নড়ে না)
- একটা-একটা / সব-একসাথে ভিউ, A+/A− ফন্ট, কিবোর্ড শর্টকাট (১–৪ / a–d, ← →), ডার্ক মোড
- ⬇⬆ ব্যাকআপ/রিস্টোর (ফলাফল ও ভুলের খাতা শুধু ব্রাউজারে থাকে, তাই ফোন/পিসি বদলালে কাজে লাগে)
